FitBot AI – Intelligent Fitness Coach Chatbot
Overview

FitBot AI is a full-stack AI-powered fitness chatbot designed to provide users with reliable fitness guidance through natural language conversations. The application leverages the Google Gemini 2.5 Flash API to generate intelligent responses related to workouts, nutrition, exercise techniques, muscle gain, fat loss, and general fitness.

In addition to AI-powered conversations, FitBot includes a dedicated Workout Form section that provides exercise descriptions along with YouTube tutorial links, allowing users to learn proper exercise techniques.

This project demonstrates practical implementation of Large Language Models (LLMs), REST APIs, prompt engineering, and full-stack web development.

Installation
Clone the repository
git clone <repository-url>

Navigate to the project directory.

cd FitBot-Chatbot
Backend Setup

Navigate to the backend folder.

cd backend

Install dependencies.

npm install

Create a .env file inside the backend directory.

GEMINI_API_KEY=YOUR_GEMINI_API_KEY

Start the backend server.

node index.js

The backend will run on:

http://localhost:5000
Frontend Setup

Open a new terminal.

Navigate to the frontend folder.

cd frontend

Install dependencies.

npm install

Start the React application.

npm start

The frontend will run on:

http://localhost:3000
